# Career e-Portfolio

Static site. No build step.

## Deploy on GitHub Pages
1. Create a public repo named `<your-username>.github.io` (or any name, e.g. `portfolio`).
2. Upload everything in this folder: `index.html`, `resume.pdf`, `images/`.
3. Repo Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
4. Wait 1-2 minutes. Your site is at `https://<your-username>.github.io/` (or `/portfolio/` for a project repo).

## Fill in
- Search `index.html` for `TODO` and replace each `#` (GitHub repos, ResearchGate paper).
- Put screenshots in `images/` named `agilapost.png`, `taxi-warehouse.png`, `game-db.png`, `java-game.png`, `web-forum.png`. Missing images are hidden automatically.
- Work/volunteer samples and references are commented out in `index.html`. Uncomment them if you have content.
- If `resume.pdf` is missing, export your resume to PDF and name it `resume.pdf`.
